🤖 AI 분석용 내보내기

검색 결과를 AI(Copilot 등)가 읽기 좋은 JSON 으로 정리하고, 이슈별 분류·요약을 시키는 지시문을 함께 만듭니다. JSON 파일을 첨부하고 지시문을 붙여넣으면 됩니다.
발췌 = 기사 앞부분 2~3문장 + 회사명이 나오는 문장. 기자 이름·저작권 문구 등은 제거되고, 제목이 거의 같은 기사는 하나로 합쳐집니다.

이 도구로 할 수 있는 것

  1. 회사명으로 네이버 뉴스를 기간을 정해 모으고, 표로 보거나 CSV / 엑셀로 내려받습니다.
  2. 모은 기사를 AI(Copilot)에 넘겨 이슈별 일자·요약·대표 기사 링크를 표와 엑셀로 받습니다.
처음 한 번은 본인의 NAVER API HUB 키(Client ID / Client Secret)를 발급받아야 합니다. 아래 1번부터 따라 하세요.

1. NAVER API HUB 키 발급 (처음 한 번)

① NAVER Cloud 콘솔 로그인

NAVER Cloud 콘솔에 로그인합니다.

② NAVER API HUB 에서 Application 등록

Application Services → NAVER API HUB → Application 으로 이동해 새 Application 을 등록합니다. 이름은 자유롭게 정하면 됩니다 (예: NewsCollector).

③ "뉴스" API 선택 후 저장

API 목록에서 뉴스 (NAVER_SCH_NEWS) 를 체크하고 저장합니다. 체크만 하고 저장하지 않으면 검색 시 "권한 없음" 오류가 납니다.

④ (필요한 경우) Subscription 확인

저장했는데도 "권한 없음" 오류가 나면, 왼쪽 Subscription 메뉴에서 검색 API 가 구독되어 있는지 확인하세요.

⑤ Client ID / Client Secret 복사

등록한 Application 의 인증 정보에서 Client ID 와 Client Secret 을 복사해 둡니다.

2. 키 입력

검색 탭 맨 위 🔑 NAVER API HUB 인증 정보 칸에 복사한 Client ID / Client Secret 을 붙여넣습니다.

  • 이 브라우저에 저장을 켜 두면 다음부터 다시 입력하지 않아도 됩니다. 공용 PC라면 끄세요.
  • 키는 검색할 때 네이버 호출에만 쓰이고, 서버에 저장되지 않습니다.

3. 검색하고 내려받기

  1. 검색 키워드: 회사명을 입력합니다. 기사마다 부르는 이름이 다르면 쉼표로 여러 개 입력하세요 (예: 포스코인터내셔널, 포스코인터). 이름마다 따로 검색해 중복을 합친 하나의 결과로 보여줍니다.
  2. 시작일 / 종료일: 모을 기간을 정합니다.
  3. 최대 수집 건수: 이름 하나당 최대 몇 건을 모을지 정합니다 (최대 1,000).
  4. 기사 본문 전체 수집: 켜면 기사 링크에 접속해 본문까지 가져옵니다(느림). 끄면 네이버가 주는 짧은 요약만 씁니다(빠름).
  5. 검색 → 표에서 확인 → CSV 다운로드 / Excel 다운로드
네이버 API 는 검색어 하나당 1,000건까지만 주고 기간 지정 기능이 없습니다. 기사가 많은 회사를 긴 기간으로 검색하면 "최신순 검색은 ○○까지만 닿았습니다" 경고가 뜨고, 그 이전 기간은 관련도 높은 기사 위주로만 채워집니다.

4. AI(Copilot)로 이슈 정리하기

  1. 검색 결과 아래 🤖 AI 분석용 내보내기 에서 회사명과 다른 이름을 확인합니다. (검색 키워드가 자동으로 들어갑니다)
  2. JSON 내보내기 를 눌러 파일을 저장합니다.
  3. 지시문 복사 를 누릅니다.
  4. Copilot 에서 새 대화를 열고, 저장한 JSON 파일을 첨부한 뒤 지시문을 붙여넣어 보냅니다.
  5. 이슈별 일자 · 이슈 · 요약 · 대표 기사 링크가 표와 엑셀 파일로 나옵니다. (엑셀을 못 만드는 환경이면 CSV 로 나옵니다)
JSON 이 여러 개로 나뉘어 저장되면(기사가 많을 때) 지시문 안내대로 1번 파일부터 순서대로 보내세요.
