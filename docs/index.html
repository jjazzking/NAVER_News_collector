네이버 뉴스 검색 정리 툴

회사 이름으로 기간 내 뉴스를 모으고, AI 이슈 분석용 파일까지 한 번에 만듭니다.
키 발급 방법은 이용 안내 탭을 참고하세요. 키는 검색할 때 네이버 호출에만 쓰이고, 서버에 저장되지 않습니다.
회사를 부르는 이름이 여러 개면 쉼표로 구분해 입력하세요. 이름마다 따로 검색해 하나의 결과로 합칩니다.

🤖 AI 분석용 내보내기

검색 결과를 AI(Copilot 등)가 읽기 좋은 JSON 으로 정리하고, 이슈별 분류·요약을 시키는 지시문을 함께 만듭니다. JSON 파일을 첨부하고 지시문을 붙여넣으면 됩니다.
발췌 = 기사 앞부분 2~3문장 + 회사명이 나오는 문장. 기자 이름·저작권 문구 등은 제거되고, 제목이 거의 같은 기사는 하나로 합쳐집니다.

처음 쓰는 경우 먼저 NAVER API HUB 키 발급·입력(아래)을 한 번 해 두세요.

1

검색

  1. 검색 키워드: 회사명을 입력합니다. 기사마다 부르는 이름이 다르면 쉼표로 여러 개 입력하세요 (예: 포스코인터내셔널, 포스코인터).
  2. 시작일 / 종료일: 모을 기간을 정합니다.
  3. 최대 수집 건수는 1,000 으로 두는 것을 추천합니다. 기사를 많이 모을수록 기간 전체가 고르게 채워집니다.
  4. 기사 본문 전체 수집은 켜 두세요. AI 가 요약을 더 정확하게 합니다.
  5. 검색을 누릅니다.
⏳ 1,000건에 본문까지 모으면 시간이 꽤 걸립니다. 검색을 눌러 두고 잠시 다른 작업을 하다 돌아오세요. 진행 상황은 검색 버튼 옆에 표시됩니다. 그동안 이 창을 닫거나 새로고침하지 마세요 (다른 탭·프로그램으로 옮겨 가는 것은 괜찮습니다).

결과를 표로 보거나 CSV / Excel 다운로드로 그대로 받을 수도 있습니다.

2

JSON 다운로드 & 지시문 복사

  1. 회사명·다른 이름이 맞는지 확인합니다 (검색 키워드가 자동으로 들어갑니다).
  2. JSON 내보내기를 눌러 파일을 저장합니다.
  3. 지시문 복사를 누릅니다.
기사가 많으면 JSON 이 여러 개(part1of2, part2of2 …)로 나뉘어 저장됩니다. 3단계에서 모든 파일을 한 번에 첨부하면 됩니다.
3

Copilot 에 업로드 & 지시문 보내기

⚠ 모델은 반드시 Opus 로 선택하세요. 다른 모델은 이슈 분류·요약 품질이 크게 떨어지거나 지시한 형식을 지키지 않을 수 있습니다.

Copilot 에서 새 대화를 열고 그림의 번호 순서대로 진행합니다.

  1. 왼쪽 위 모델 선택(기본값 "자동")을 누릅니다.
  2. Claude → Opus 를 선택합니다.
  3. 2단계에서 저장한 JSON 파일을 첨부합니다 (여러 개면 모두 한 번에).
  4. 복사한 지시문을 붙여넣습니다.
  5. 보내기를 누릅니다.

잠시 뒤 이슈별 일자 · 이슈 · 요약 · 대표 기사 링크가 표와 엑셀 파일로 나옵니다. (엑셀을 못 만드는 환경이면 CSV 로 나옵니다)

🔍 결과물은 마지막에 꼭 검토하세요. 이 툴은 회사 이름이 들어간 기사를 모두 모으기 때문에, 회사와 직접 관련 없는 기사(다른 회사 기사에 이름만 스친 경우, 동명이인·비슷한 이름 등)가 섞이거나, AI 가 이슈를 잘못 묶거나 요약을 부정확하게 할 수 있습니다. 보고에 쓰기 전에 대표 기사 링크를 열어 내용과 일자를 확인하고, 관계없는 이슈는 지우거나 고쳐 주세요.

처음 한 번: NAVER API HUB 키 발급 · 입력

검색하려면 본인의 NAVER API HUB 키(Client ID / Client Secret)가 필요합니다.

① NAVER Cloud 로그인 → 콘솔

www.ncloud.com 에 로그인한 뒤 오른쪽 위 콘솔을 누릅니다.

② 콘솔에서 Menu 열기

콘솔 왼쪽 위 Menu 를 누릅니다.

③ NAVER API HUB 선택

NAVER API HUB 를 누릅니다. 목록에 없으면 All Services → Application Services 에서 찾거나, 위쪽 검색창에 "NAVER API HUB" 를 검색하세요.

④ Application 등록

+ Application 등록 을 누릅니다.

⑤ API 선택: "뉴스" 체크 → 다음

API 목록에서 뉴스 (NAVER Search News API) 카드를 체크하고 아래 다음을 누릅니다.

⑥ Application 이름 입력 → 완료

이름은 자유롭게 정하면 됩니다 (예: NewsCollector). 입력 후 완료를 누릅니다.

이미 만든 Application 이 있다면? (클릭)

새로 만들지 않고, 기존 Application 의 수정 화면에서 뉴스를 체크하고 저장해도 됩니다. 체크만 하고 저장하지 않으면 검색 시 "권한 없음" 오류가 납니다.

"권한 없음" 오류가 나면 왼쪽 Subscription 메뉴에서 검색 API 가 구독되어 있는지 확인하세요.

⑦ 인증 정보에서 Client ID / Client Secret 복사

만든 Application 을 선택하고 인증 정보를 눌러 Client ID 와 Client Secret 을 복사합니다.

⑧ 이 사이트에 키 입력

검색 탭 맨 위 🔑 NAVER API HUB 인증 정보 칸에 붙여넣습니다. 이 브라우저에 저장을 켜 두면 다음부터 다시 입력하지 않아도 됩니다 (공용 PC라면 끄세요). 키는 검색할 때 네이버 호출에만 쓰이고, 서버에 저장되지 않습니다.
