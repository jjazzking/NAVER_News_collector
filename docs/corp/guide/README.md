# 이용 안내 캡처

배포용 사이트 "이용 안내" 탭에 표시되는 캡처 이미지입니다. 아래 이름으로 PNG 파일을 넣으면 자동으로 표시되고,
파일이 없으면 "캡처 준비 중" 자리가 표시됩니다.

| 파일 | 내용 |
|---|---|
| `01-console.png` | NAVER Cloud 콘솔 첫 화면 |
| `02-application.png` | NAVER API HUB → Application 등록 화면 |
| `03-select-news.png` | API 목록에서 "뉴스" 체크 → 저장 |
| `04-subscription.png` | Subscription 메뉴 |
| `05-credentials.png` | Application 인증 정보 (Client ID / Secret — 실제 키는 가려서 캡처) |
| `06-enter-key.png` | 이 사이트의 키 입력 칸 |
| `07-search.png` | 검색 결과 화면 |
| `08-ai-export.png` | AI 분석용 내보내기 |
| `09-copilot.png` | Copilot 에 JSON 첨부 + 지시문 붙여넣기 |
